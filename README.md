## Guido Dinello

Full stack AI engineer in Uruguay. At [Light-it](https://lightit.io) I build LLM and RAG features for HIPAA-regulated healthcare products, using Python and FastAPI, React + TypeScript and AWS, and take them from client discovery to production.

Outside work I study reinforcement learning and Monte Carlo methods through games, and build tools for AI-assisted development.

### Selected projects

- **[proyecto-de-grado-openfing-rag](https://github.com/guidodinello/proyecto-de-grado-openfing-rag):** my thesis at Universidad de la República. It's a RAG assistant over 4,300+ recorded lectures from 239 courses, and every answer cites the lecture and the exact second of the video. Built with FastAPI, pgvector and Whisper transcription.
- **[catan](https://github.com/guidodinello/catan) · [truco-py](https://github.com/guidodinello/truco-py) · [gamekit](https://github.com/guidodinello/gamekit):** game engines and reinforcement-learning agents (MaskablePPO, self-play, action masking), plus a shared library for Monte Carlo statistics used in pre-registered experiments.
- **[claude-client](https://github.com/guidodinello/claude-client) · [herdr-routines](https://github.com/guidodinello/herdr-routines) · [claude-dotfiles](https://github.com/guidodinello/claude-dotfiles):** tooling for working with Claude Code and AI coding agents.
- **[pullscope](https://github.com/guidodinello/pullscope):** browser extension that applies saved filters to GitHub pull-request pages (WXT, Svelte 5, TypeScript).
